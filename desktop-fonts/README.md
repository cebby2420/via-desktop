# Desktop fonts

The unmodified Fira Sans and Fira Sans Condensed fonts come from
[Google Fonts revision 5bb28733](https://github.com/google/fonts/tree/5bb28733cec313b63fbd415b574b5ae35c8aa8b8/ofl).
Each family is provided under the SIL Open Font License 1.1. See the two
OFL files for the original copyright and licence notices.

VIA draws key legends only once the bold Fira Sans face is ready. The
desktop server uses this local stylesheet and starts loading the bold
face so the legends work offline.
